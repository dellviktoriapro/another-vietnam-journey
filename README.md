# Другой Вьетнам

Презентационный сайт тура Муйне — Халонг — Сапа для туроператоров.

После обложки показана статичная карта. Отдельная объёмная карусель с фотографиями переключает пункты маршрута стрелками и прокруткой страницы. Программа представлена тремя сменяющимися экранами дней; полный тайминг раскрывается в каждом экране. Предусмотрены мобильная версия, управление с клавиатуры, режим уменьшенного движения и печать подробной программы.

Страница работает без сборки: запустите локальный HTTP-сервер или откройте GitHub Pages. Фотографии, авторство и источники — в PHOTO-SOURCES.md и в подвале страницы.
