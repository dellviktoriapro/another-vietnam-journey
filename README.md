# Другой Вьетнам

Интерактивный маршрут Муйне — Халонг — Сапа для туристического агентства.

Статическая страница с анимацией маршрута при прокрутке. Откройте `index.html` через локальный HTTP-сервер или GitHub Pages.

Авторство фотографий и ссылки на источники указаны внизу страницы. Фотографии сохраняют свои исходные лицензии.
